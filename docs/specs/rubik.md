# 仕様書 — ルービックキューブ (`rubik.html`)

作成日: 2026-06-12

---

## 概要

3D表示のルービックキューブを指で操作して遊ぶコンテンツ。
- 背景（キューブ以外）を指でなぞる → キューブ全体の向き（視点）を回転
- キューブの面をフリックする → その面を含む1列（レイヤー）を90度回転

実際のルービックキューブと同じ回転ロジックを実装し、シャッフル後も
必ず6面を揃えられる状態（=有効な操作のみで状態遷移する）を保証する。

## 対象ユーザー

5歳〜小学生。シンプル操作（2x2）から本格（3x3）まで選べる。

## 内部データモデル（正しさの保証）

- ワールド座標系: X+=右, Y+=下, Z+=手前（CSS座標系と一致させる）
- キューブは N×N×N 個の「キュービー」で構成（N=2 or 3）
  - 各キュービーは `pos`（グリッド座標ベクトル）と `orient`（3x3回転行列、初期値は単位行列）を持つ
  - 各キュービーは生成時に固定の `baseColors`（ローカル面方向→色 or 'plastic'）を持ち、以後変化しない
- レイヤー回転（軸 axis, 角度 ±90°）:
  - 対象キュービー = `pos[axis] === layerCoord` のもの全て
  - `pos' = R(axis,angle) * pos`
  - `orient' = R(axis,angle) * orient`
  - 描画は `translate3d(pos) matrix3d(orient)` のみで決まるため、状態更新がそのまま見た目に反映される
- 完成判定: ワールドの6方向それぞれについて、その面に露出しているキュービーの
  現在の色（`baseColors[ orient^T * worldDir ]`）が全て同一であること

### 操作 → 回転軸/方向の決定

1. タップしたキュービー面の固定ローカル法線 `localNormal` から
   `worldNormal = orient * localNormal` を求める
2. `worldNormal` の軸を除く2軸（面内軸）について、現在の視点回転行列
   `viewM = Rx(viewRx) * Ry(viewRy)` で画面へ投影し、フリック方向 (dx,dy) と
   最も一致する軸を「スワイプ軸」、もう一方を「回転軸 axisRot」とする
3. `layerCoord = pos[axisRot]`
4. 回転方向の符号は、`axisRot × (pos + worldNormal*0.5)` を `viewM` で
   画面へ投影したベクトルとスワイプ方向の内積の符号で決定する
   （+なら+90°、-なら-90°）

この一連の計算により、見た目の操作感と内部状態が常に一致し、
不正な状態（揃わない配置）になることはない。

## 操作仕様

- **キューブ以外（背景）をドラッグ**: 視点のみ回転（`viewRx`/`viewRy` を更新し
  `#cube-group` の `rotateX/rotateY` に反映。状態には影響しない）
- **キューブの面をフリック**（移動距離 15px 以上）: 該当レイヤーを90度回転
  （0.25秒アニメーション）。回転中は新規操作を無視する
- アニメーション中はタイマー・手数の表示を更新（手数はレイヤー回転完了時に+1）

---

## サイズ選択

- **2x2（かんたん）**: 8キュービー、色は6色固定
- **3x3（ほんかく）**: 27キュービー（中心・内部含む）

色配置（標準的なルービックキューブ配色）:
| 方向 | 色 |
|---|---|
| 右 (+X) | 赤 |
| 左 (-X) | オレンジ |
| 下 (+Y) | 黄 |
| 上 (-Y) | 白 |
| 前 (+Z) | 緑 |
| 後 (-Z) | 青 |

---

## 機能要件

- **シャッフル**: ランダムな軸・方向の回転を15〜25回、アニメーション無しで即時適用
  → タイマー・手数を0にリセットしてスタート
- **リセット**: 揃った状態に戻す
- **タイマー**: シャッフル後、最初の操作で開始。揃ったら停止
- **手数カウント**: レイヤー回転が完了するごとに+1
- **完成演出**: 6面揃ったらオーバーレイ表示（紙吹雪 + 時間/手数 + 再シャッフル/タイトルへ）
